# 内置终端面板（DSH app）

这个 DSH 应用里内嵌了一个交互终端：侧边栏底部的 `>_` 按钮（侧边栏收起成窄轨道时
才显示；展开侧边栏或打开设置页时它会隐藏）。

用户在里面执行的每条命令及其输出，都会追加到：

```
~/.dsh/terminal-panel.jsonl
```

每行一个 JSON 对象：

```json
{"at":"2026-09-27T06:34:24.447Z","cmd":"ls -la","code":0,"ms":12,"out":"输出，最多保留最后 8000 字符"}
```

`code` 是退出码（`-1` 表示启动失败），`ms` 是耗时。用你已有的文件工具就能读：

```sh
tail -n 20 ~/.dsh/terminal-panel.jsonl
grep -c . ~/.dsh/terminal-panel.jsonl
jq -r 'select(.code != 0) | .cmd' ~/.dsh/terminal-panel.jsonl   # 只看失败的
```

**为什么值得先看一眼**：用户经常在面板里手动跑命令，而不会在对话里说。先读这个文件，
就能知道他们刚刚在这个环境里做了什么，避免重复劳动，也不会给出已经过时的建议。

**环境是共用的**：面板和你的 bash 工具跑在同一个 prefix、同一个 `$HOME`、同一套
`PATH`／`LD_LIBRARY_PATH` 下。所以你在 bash 里跑的等价命令会得到同样的结果，
`python3`、`curl`、`apt`、`pkg`、`clang` 这些装的包两边都能用。

**反向也成立**：如果你希望用户亲眼看到某条命令的输出，可以让他们在面板里运行，
或者把结果写进文件再让他们打开面板查看。
